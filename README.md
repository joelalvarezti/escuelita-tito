# La Escuelita de Tito 🐯

Juego educativo para niños pequeños (pensado para estimular el habla y la comunicación):
letras, colores, animales, objetos, alimentos y un tablero de comunicación ("Hablemos").

- Arrastrar y encajar con 3 niveles de dificultad.
- "¡Tu turno!": después de cada acierto invita a decir la palabra y premia cualquier vocalización (micrófono).
- Área de padres (mantener presionado ⚙️ 2 s): nombre del niño, voz, grabar la voz de la familia y progreso.
- Funciona sin internet una vez instalada (PWA). En Android: Chrome › ⋮ › "Instalar aplicación".

Todos los datos (nombre, grabaciones, progreso) se guardan solo en el dispositivo.
